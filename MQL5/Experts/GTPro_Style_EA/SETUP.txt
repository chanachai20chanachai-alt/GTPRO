# GTPro Style SMC EA V1
File: MQL5/Experts/GTPro_Style_EA/GTPro_Style_EA.mq5

This is an independent SMC interpretation of chart screenshots, NOT the proprietary GTpro formula.

Modes: Trend (EMA100/200, ADX, BOS and 3-candle FVG retest); Reversal (confirmed pivot sweep followed by internal CHoCH proxy); Hybrid (both).
Safeguards: 1 position per symbol, spread filter, equity-based lot size, SL+TP, optional break-even/trailing, drawdown blocks for new orders, no grid/martingale.

DEFAULT InpEnableAutoTrading=false. For order simulations enable it explicitly within Strategy Tester.

IMPORTANT: the code has been written to GitHub but NOT compiled on Windows MetaEditor and NOT backtested on MT5. Please use Codex to open this repo, run MetaEditor F7 compile, resolve any compiler warnings/errors, then test Every tick based on real ticks. Do not run live without verifying signal timestamps and risk/SL execution.

This V1 does not reproduce all GTpro drawings; for example session boxes, supply/demand overlays, and the full multi-timeframe dashboard are not implemented. Equity guards block NEW trades; they do not close existing positions and reset their references on EA restart.

Steps: In Codex open chanachai20chanachai-alt/GTPRO and pull main. Copy the .mq5 to your MT5 File > Open Data Folder > MQL5 > Experts > GTPro_Style_EA; open in MetaEditor and compile (F7). Use Ctrl+R in MT5 for Strategy Tester.
